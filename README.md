# Shuffle Mobile — Project Case Study

Shuffle Mobile is a collaborative mobile application project focused on discovering and organising events.

The application is being developed collaboratively in a private GitHub organisation repository.

This case study documents my individual contributions to the mobile project without exposing the private source code.

## My contributions

My work on the mobile application has included:

- Reusable mobile UI components
- UI architecture and design-system improvements
- Form styling and error handling
- Typography system improvements
- Country-related state and offline data handling
- UI-library migration and refactoring
- Expo and native dependency alignment
- Project configuration and development cleanup

- ## Technologies

- React Native
- Expo
- TypeScript
- Git / GitHub
